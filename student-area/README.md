# Student Area Context

Esta pasta contém materiais de referência para o desenvolvimento da área do aluno do Michela Ensina.

A área do aluno será um app separado da landing page, com foco em produto, autenticação, consumo de aulas/materiais e experiência logada.

## Direção visual

- Dark mode como padrão.
- Visual mais limpo e funcional que a LP.
- Preservar a identidade Michela Ensina sem copiar o excesso decorativo da landing.
- Usar a paleta escura definida em `globals.dark.css`.
- Usar o documento de decisões de design como referência principal.

## Atenção

A landing page de pré-lançamento usa uma escala visual maior no desktop e uma linguagem mais promocional.  
Essas decisões não devem vazar automaticamente para a área do aluno.

A área do aluno deve priorizar:
- legibilidade;
- navegação clara;
- contraste;
- estados de loading/error/empty;
- responsividade;
- integração segura com o backend.
